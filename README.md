# Três Derivações do Termo de Competição em Equações Mestras Quânticas

Este projeto implementa três derivações microscópicas de um termo não‑linear de competição (`C(ρ) = ρ² − ρ Tr(ρ²)`) que atua como purificador em sistemas quânticos abertos.

## Derivações
- **A – Campo médio de N corpos**: interação coletiva entre cópias idênticas.
- **B – Colisão adaptativa**: ancillas que aprendem o estado do sistema (mapa CP).
- **C – Eliminação adiabática de 2ª ordem**: acoplamento a um banho não‑Markoviano.
